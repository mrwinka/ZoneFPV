# Публикация ZoneFPV 0.3.0 RC2 — 16 октября 2026

**Исправленный установщик опубликован на GitHub и Nexus. GitHub проверен скачиванием; Nexus поместил новый файл в карантин, и загрузка оттуда пока недоступна.**

## Что изменилось

Это обновление только установщика, версия остаётся **0.3.0 RC2**. Недоступные библиотеки Steam, включая отключённые диски, больше не прерывают поиск игры. Сохранились ручной выбор папки и параметр `-GameRoot`; команда приведена в [INSTALLER_UPDATE.md](INSTALLER_UPDATE.md). Все **114 runtime-файлов и PAK** совпадают с предыдущей RC2. Новых игровых функций в этом исправлении нет.

Описание файла сохранено и прочитано публично; публичная ссылка VirusTotal содержит правильный SHA-256 архива. Начальная RC2 **20686** и RC1 **20277** перенесены/сохранены в **Old Files**. Стабильная **0.2.0 / 20042** остаётся в Main Files.

**Новый файл находится в карантине автоматической проверки Nexus, а не просто ожидает завершения сканирования.** Скачать его с Nexus сейчас нельзя; завершение проверки и сверка скачивания Nexus не заявляются. Сайт показывает **26 записей / 14 уникальных**: Add changelog добавил строки в ту же версию и повторил 12 прежних записей. Добавление примечания установщика в главное описание также завершилось HTTP 403, поэтому публикация этого добавленного абзаца не заявляется.

## Проверки

Под **Windows PowerShell 5.1.26100.9444** прошли regression поиска Steam, полная установка/обновление с сохранением настроек, аварийный откат, удаление и настройки runtime. Игровые файлы не менялись: предыдущие **74 Lua-набора / 155 синтаксических проверок**, native/helper и PAK доказательства переиспользованы без повторного запуска. Новая проверка функций в игре или численный прирост FPS не заявляются. Старые локальные архивы сохранены отдельно.
