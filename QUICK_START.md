# ZoneFPV quick start / Быстрый старт

1. Install game-compatible UE4SS separately; keep its settings (EngineTick is supported).
2. Close the game, extract this archive, run **Setup.cmd**.
3. Connect your controller, launch the game and load a save.
4. **F6**: select a device, verify directions and calibrate if needed.
5. Low throttle for Acro/Angle, centered throttle for 3D. **F8**: enter/exit FPV. **F9**: return to launch.

Для установки: закройте игру → распакуйте архив → **Setup.cmd**. После загрузки сохранения: **F6** — контроллер/настройки, **F8** — FPV, **F9** — возврат к старту. UE4SS устанавливается отдельно; настройки и калибровки сохраняются при обновлении.
