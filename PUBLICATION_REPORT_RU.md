# Отчёт о публикации ZoneFPV v58 — 8 октября 2026

GitHub опубликован: https://github.com/mrwinka/ZoneFPV/releases/tag/v0.3.0-rc1-v58

Исходники и README на английском/русском, установка, описание функций, список изменений, статус проверок и сведения для review обновлены. Выпуск отмечен как предварительный; 0.2.0 остаётся последним стабильным, прежние файлы сохранены. Приложены установочный ZIP, контрольные суммы и публичный отчёт проверки. Все три файла повторно скачаны и сверены по SHA-256.

Опубликованы накопленные изменения 0.3.0: настройки внутри КПК и F6, вертикальная прокрутка, редактор OSD с перетаскиванием и всеми показателями, произвольные кнопки/CH и удержание, нижняя камера/фонарик/видение, камикадзе/сброс/совмещённый режим, сбор артефактов и симуляция сигнала. Последние исправления касаются ожидания поздней загрузки NPC и проверки владельца всей цепочки снаряжения. Исходное обновление компонента движения сохранено.

66 Lua-наборов и синтаксис 139 файлов прошли. Проверены установленные файлы и публичный установщик на тестовой установке/обновлении/удалении. Результаты подтверждают офлайн-проверки; исчезновение моделей NPC и восстановление сканера в игре ещё не подтверждены.

Nexus не опубликован: https://www.nexusmods.com/stalker2heartofchornobyl/mods/2799

Доступный браузер требует входа в аккаунт. Тот же ZIP, описание EN/RU и примечания к файлу подготовлены. После авторизации остаётся загрузить новый предварительный файл и обновить описание/журнал, сохранив старые выпуски.
