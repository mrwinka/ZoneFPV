# ZoneFPV 0.3.0 RC2 — quick start / Быстрый старт

## English

1. Install game-compatible UE4SS separately. Close the game, extract all of **ZoneFPV-0.3.0-RC2.zip**, run **Setup.cmd**, then start the game and load a save.
2. Open **PDA → ZoneFPV** or **F6**. Both menus share settings; all tools work inside the PDA.
3. **Settings → Controller:** select your USB Joystick transmitter/gamepad, check directions and calibrate four axes. **Settings → Buttons:** press-to-bind keyboard/mouse/controller/CH; choose Toggle or Hold.
4. **Flight → Main:** battery simulation, **300–20000 mAh, 2–8S**, default 1500 mAh/6S. New flight = full pack; F9 keeps remaining charge; menu/focus pauses do not drain it. Disable simulation if desired.
5. **Equipment → Combat mode:** unarmed, kamikaze, grenade drop or combined. Set appropriate impact power/speed or RGD-5/F-1 and 1–20/unlimited charges. Held release repeats; F9 does not refill ammunition.
6. **Equipment → Scanner:** scanning/collection controls, artifact reach **0.5–10 m**. Bind collection in Settings → Buttons. **Image → Camera:** choose vision and permit lower camera/flashlight inputs; permission alone does not activate them.
7. **Image → OSD:** click/drag preview items; set size, colour and display. Normal/downward crosshairs are separate; the horizon hides below. Battery telemetry is a configurable item.
8. Lower throttle in Acro/Angle or centre it in 3D. **F8** enters/leaves FPV; **F9** returns to launch; **F6** opens settings. Close settings/PDA to fly.

Preferences/calibration/OSD layout are preserved on update. Restart after updating the complete Lua/EXE/DLL/PAK set. See [installation and troubleshooting](SITE_INSTALL.md) and [RC2 changes](RELEASE_NOTES.md).

## Русский

1. Отдельно установите совместимый UE4SS. Закройте игру, полностью распакуйте **ZoneFPV-0.3.0-RC2.zip**, запустите **Setup.cmd**, затем игру и сохранение.
2. Откройте **КПК → ZoneFPV** или **F6**. Настройки общие; все инструменты работают внутри КПК.
3. **«Настройки → Пульт»**: выберите USB Joystick-пульт/геймпад, проверьте направления и откалибруйте четыре оси. **«Настройки → Кнопки»**: нажмите назначение и кнопку клавиатуры/мыши/пульта или CH; выберите переключение либо удержание.
4. **«Полёт → Основное»**: эмуляция батареи **300–20000 mAh, 2–8S**, по умолчанию 1500 mAh/6S. Новый полёт заряжает батарею, F9 сохраняет остаток; меню/потеря фокуса её не расходуют. Эмуляцию можно отключить.
5. **«Оснащение → Боевой режим»**: обычный, камикадзе, сброс гранат или совмещённый. Настройте подходящие параметры удара либо RGD-5/F-1 и 1–20/неограниченные заряды. Удержание повторяет сброс; F9 боезапас не пополняет.
6. **«Оснащение → Сканер»**: сканирование/сбор, дальность подбора артефакта **0,5–10 м**. Кнопка сбора назначается в настройках кнопок. **«Изображение → Камера»**: видение, разрешение нижней камеры и фонарика; само разрешение функцию не включает.
7. **«Изображение → OSD»**: нажмите и перетащите элемент предпросмотра, задайте размер, цвет и отображение. Обычный и нижний прицелы отдельные; при взгляде вниз горизонт скрывается. Батарея — настраиваемый показатель.
8. В Acro/Angle опустите газ, в 3D держите по центру. **F8** — вход/выход из FPV, **F9** — возврат к старту, **F6** — настройки. Для полёта закройте меню/КПК.

При обновлении сохраняются настройки, калибровка и OSD. Обновляйте Lua/EXE/DLL/PAK вместе и перезапускайте игру. [Установка и помощь](SITE_INSTALL.md), [изменения RC2](RELEASE_NOTES.md).
