# Отчёт об исправлении установщика ZoneFPV 0.3.0 RC2

16 октября 2026. Исправлено прекращение установки из-за библиотеки Steam на отсутствующем диске. Setup пропускает такую библиотеку и продолжает поиск; ручной путь `-GameRoot` сохранён. **Игровой код, EXE/DLL/PAK, функции и настройки не изменены.**

## Опубликовано

- **GitHub:** обновлены три вложения существующего [выпуска RC2](https://github.com/mrwinka/ZoneFPV/releases/tag/v0.3.0-rc2), release **415267341**. ZIP **648329625**, verification **648329770**, sums **648329806** повторно скачаны; все хеши совпали. ZIP: **1 136 193 байта**, SHA-256 **45CC7827C917A14DAF0446BFA0851E9F74BA8B1B211D55DD1945E6EF3B2BA2B4**.
- **Исходники:** [commit `4354613`](https://github.com/mrwinka/ZoneFPV/commit/435461369da80b5c4a5beeae295fe2cd5ab60dd8), 292 файла; точные пять изменений сверены. Тег RC2 сохраняет исходную игровую сборку `942cd0d`; новый commit установщика и [инструкция](https://github.com/mrwinka/ZoneFPV/blob/435461369da80b5c4a5beeae295fe2cd5ab60dd8/INSTALLER_UPDATE.md) указаны в описании выпуска.
- **Nexus:** новый файл **20688 — ZoneFPV 0.3.0 RC2 - installer fix** опубликован в **Main Files / Primary**. Описание файла публично проверено; ссылка VirusTotal указывает тот же SHA-256. Начальная RC2 **20686** и RC1 **20277** сохранены в Old Files; стабильная **0.2.0 / 20042** остаётся в Main Files.

## Что пока недоступно

Nexus поместил файл **20688 в карантин автоматической проверки**. Сейчас скачать его там нельзя; проверка Nexus не объявляется завершённой, повторное скачивание с Nexus не подтверждено. Доступное и проверенное зеркало — GitHub.

Две новые строки журнала об установщике EN/RU опубликованы и прочитаны публично. В журнале **26 записей / 14 уникальных**: сайт добавил строки в ту же версию и продублировал 12 старых. Три попытки удалить дубли через Edit changelog получили HTTP 403; старые дубли остались. Главное описание функций RC2 сохраняется; попытка добавить в него примечание установщика также получила HTTP 403. Добавленный абзац в главном описании не считается опубликованным.

## Проверки и состав

Под Windows PowerShell **5.1.26100.9444** прошли поиск при недоступном диске, ручной `-GameRoot`, установка/обновление/откат, удаление и сохранение runtime-настроек. В архиве **132 файла**; все **114 runtime-файлов и PAK** побайтово совпадают с предыдущей RC2. Из записей архива изменены только `Setup.ps1`, `VERIFICATION.json`, `SHA256SUMS.txt`. Предыдущие Lua/native/PAK проверки переиспользованы; игровой код не менялся, новые игровые результаты не заявляются. Старый опубликованный архив сохранён локально отдельно.
