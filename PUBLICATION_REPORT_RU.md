# Публикация ZoneFPV 0.3.0 RC1 — 8 октября 2026

**GitHub обновлён:** [ZoneFPV 0.3.0 RC1](https://github.com/mrwinka/ZoneFPV/releases/tag/v0.3.0-rc1) — текущий рекомендуемый выпуск с отметкой **Latest**. Обновлены исходники, README EN/RU, установка, описание функций, журнал изменений и проверочные сведения. Версия остаётся кандидатом в релиз; старые выпуски, включая проверенную автором 0.2.0, сохранены. Названия выпуска, установщика, документации и строки журнала FPV приведены к **0.3.0 RC1**, без внутреннего номера отладки.

В GitHub остались три актуальных вложения: **ZoneFPV-0.3.0-RC1.zip**, **ZoneFPV-0.3.0-RC1-verification.json** и **SHA256SUMS.txt**. Все три повторно скачаны и сверены по SHA-256. Три устаревших вложения удалены после подтверждения пользователя; старые стабильные выпуски сохранены. ZIP содержит 126 файлов, включая 109 runtime-файлов. SHA-256: `36d620a5c317650378862f66d97f697dabd048e3054d2a784e8907a5c67f2afb`.

**Nexus: перенос в Main и выбор основным выполнены.** [Страница ZoneFPV](https://www.nexusmods.com/stalker2heartofchornobyl/mods/2799) содержит версию **0.3.0-RC1**, обновлённые описания EN/RU и журнал изменений. Файл **20277** переименован в **ZoneFPV 0.3.0 RC1**, перенесён в **Main Files** рядом со старыми версиями и выбран **Primary**. В нём тот же ZIP, 1.0 МБ; на сайте указан 8 октября 2026, 8:01 AM. Эти изменения затронули только метаданные; архив не менялся. Предусмотрено ручное скачивание. Публикация выполнена через сайт, без ключа API или отдельного скрипта.

**Nexus показывает «QUARANTINED»: скачивание файла 20277 недоступно.** Перенос в Main и выбор Primary не снимают карантин. Повторная скачка и сверка Nexus-файла возможны после восстановления доступности; успешная проверка сайта не заявляется. Пока используйте установщик с GitHub.

Последние исправления: сканер ограниченно ждёт позднюю загрузку модели/мира/root живого NPC; проверка видимости отслеживает личность и владельца каждого звена снаряжения и прекращает записи после передачи родителя NPC. Сохранены изменения КПК/F6, OSD, кнопок/CH, оснащения и видения. Переименование меняет только строку журнала FPV; остальные runtime-файлы, бинарники и PAK не менялись.

Повторно прошли **66 Lua-наборов**, синтаксис **139 файлов** и изолированная установка/обновление/удаление с сохранением настроек. **`gameplay_verified=false`: исчезновение моделей NPC и восстановление сканера в игре ещё не подтверждены.** Новая сборка бинарников и измеренный прирост FPS не заявляются.

В игре остаётся проверить одновременное сканирование NPC в обычном и тепловизионном режиме, сохранность самих моделей после выхода из FPV, редактор OSD внутри КПК, назначения кнопок/CH и подключение/калибровку пульта во время игры.
