# ZoneFPV

Управляемая пультом/геймпадом FPV-камера для S.T.A.L.K.E.R. 2 с моделью полёта квадрокоптера, настраиваемым OSD и эффектами видения.

**Текущий рекомендуемый выпуск — 0.3.0 RC1.** Скачайте приложенный установщик **ZoneFPV-0.3.0-RC1.zip** из [последнего выпуска](https://github.com/mrwinka/ZoneFPV/releases/latest). Старые версии, включая проверенную автором 0.2.0, доступны в [выпусках](https://github.com/mrwinka/ZoneFPV/releases). Автоматический Source code предназначен для разработки и не содержит готовые бинарники.

## Возможности

- Acro, самовыравнивание Angle и двунаправленная тяга 3D; rates, expo, скорость и наклон камеры.
- Выбор DirectInput/XInput/WinMM, профили и калибровка четырёх осей. Пульт подключается в USB Joystick/HID.
- Все настройки внутри КПК; независимое F6 с общими настройками. Списки прокручиваются вертикально.
- Произвольные кнопки клавиатуры/мыши/пульта/CH с переключением и удержанием. Удержание сброса повторяет действие с интервалом; сбор повторяется по мере приближения.
- Перетаскиваемый предпросмотр OSD и список всех 14 показателей, включая HP, детектор и боезапас. Прицелы обычной/нижней камеры включаются и оформляются отдельно.
- Ночное/инфракрасное/тепловизионное видение, аналоговые эффекты, фонарик и нижняя камера, вращающаяся с дроном. NIR/SWIR — имитация на основе видимого изображения.
- Камикадзе, сброс и совмещённый режим; мощность/порог удара, RGD-5/F-1, 1–20 либо неограниченные заряды.
- Сканирование NPC/мутантов/аномалий, сбор артефактов с регулируемой дистанцией, симуляция сигнала, настройки времени/погоды/подгрузки и пять языков.

## Меню и управление

Откройте **КПК → ZoneFPV** или **F6**. Пять групп: **«Полёт», «Изображение», «Оснащение», «Мир и связь», «Настройки»**. Пульт/калибровка — **«Настройки → Пульт»**, назначения — **«Настройки → Кнопки»**, редактор — **«Изображение → OSD»**. В «Общие» находятся язык, звук и лимит объектов.

По умолчанию **F6 — настройки, F8 — вход/выход из FPV, F9 — возврат к старту**. В Acro/Angle опустите газ, в 3D держите по центру. Закройте меню/КПК для полёта. Переключатели фонарика/нижней камеры разрешают работу назначенной кнопки, сами функцию не включают.

## Установка

Отдельно установите UE4SS для версии игры. При закрытой игре распакуйте полный приложенный ZIP и запустите **Setup.cmd**. Подключите пульт, загрузите сохранение, выберите устройство, проверьте направления и калибровку. Обновления сохраняют настройки и резервируют предыдущий мод; UE4SS/другие моды не заменяются. Компилятор/Python пользователю не нужны. Vortex не проверен. [Установка](SITE_INSTALL.md), [требования](DEPENDENCIES.md).

## Последние исправления и ограничения

0.3.0 RC1 сохраняет ограниченное ожидание поздней загрузки модели/мира/root живого NPC и проверяет владельца/личность всей цепочки снаряжения игрока. После передачи родителя другому владельцу записи в дочерние объекты прекращаются. Исходное обновление компонента движения и диагностика v57 сохранены.

Прошли **66 Lua-наборов**, синтаксис **139 файлов** и сверка установки по хешам. Бинарники helper v55/native v51 переиспользованы без новой сборки. Эти проверки не подтверждают восстановление моделей в игре, отсутствие любых крашей или прирост FPS. [Сведения для проверки](REVIEW_NOTES.md).

Основной FPV переносит центр симуляции с дроном; альтернативный оставляет его на старте, поэтому NPC вдали/коллизии могут быть неподгружены. Отсутствующая геометрия, чёрный эффект у ЧАЭС и квестовая погода остаются возможными. Повышение подгрузки/лимита объектов увеличивает нагрузку; лимит в **«Настройки → Общие»** применяется после перезапуска. [Лимит объектов](OBJECT_LIMIT.md).

## Сборка нативных компонентов

Установите Visual Studio C++ Build Tools с x64-компилятором. В папке исходников выполните PowerShell:

```powershell
.\Build.ps1
.\Native-Build.ps1
```

`Build.ps1` собирает/копирует `mod/ZoneFPVInput.exe`. `Native-Build.ps1` собирает/проверяет/копирует `mod/ZoneFPVNative.dll`. Lua запускается из `mod/Scripts`. Установочный ZIP содержит проверенные бинарники и собственный PAK оснащения; при пересборке нужны соответствующие runtime/ассеты. Скрипты не устанавливают UE4SS.

```powershell
.\Test.ps1 -LuaPath 'C:\path\to\lua.exe'
.\Test-Native.ps1
.\tests\installer_test.ps1
```

Нужны Lua 5.4 и MSVC; Lua не включён. Тесты используют фикстуры/mocks и не заменяют проверку API игры, физического пульта и FPS. Нативные исходники — `src`, Lua — `mod/Scripts`.
