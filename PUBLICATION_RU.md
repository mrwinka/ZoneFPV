# Публикация ZoneFPV 0.3.0 RC2 — 16 октября 2026

Статус: **подготовлено, публикация ещё не подтверждена**. Пользователь сообщил, что текущая сборка в целом работает, и разрешил выпустить её как RC2, обновить описания GitHub/Nexus и отдельно получить сравнение с опубликованной RC1.

## Что публикуется

- `ZoneFPV-0.3.0-RC2.zip`: полный согласованный комплект Lua, вспомогательного EXE, native DLL и PAK.
- Манифест проверки выпуска и `SHA256SUMS.txt`.
- Открытые исходники без личных настроек, журналов, резервных копий, исследований и тестовых артефактов.
- Актуальные README EN/RU, полное описание функций, установка, журнал изменений и примечания к RC2.

RC2 добавляет батарею. Вооружение, видение, сбор артефактов и дублирование F6 внутри КПК уже были в RC1; их следует сохранить в общем описании, а не выдавать за новые RC2. Точное сравнение — `build/publish-rc2/RC2_CHANGES_RU.md`.

## GitHub

Обновить существующий репозиторий https://github.com/mrwinka/ZoneFPV, создать тег `v0.3.0-rc2` и выпуск **ZoneFPV 0.3.0 RC2** с приложенным установщиком, проверочным JSON и SHA-256. Сохранить старые выпуски. Версия остаётся кандидатом в релиз; её описание — RELEASE_NOTES.md. После публикации проверить ссылки, метаданные и повторно скачать вложения для сверки хешей.

## Nexus

Использовать существующую страницу https://www.nexusmods.com/stalker2heartofchornobyl/mods/2799. Добавить RC2 новым файлом в **Main Files**, выбрать **Primary** и обновить текущую версию страницы. Сохранить старые версии; Optional не подходит для основного установщика новой версии. Обновить полное описание EN/RU, журнал и описание нового файла по документам `build/publish-rc2/`.

Карантин/доступность определяются сайтом после загрузки. Не объявлять файл доступным или проверенным Nexus, если сайт этого не подтверждает. Сохранить видимое зеркало GitHub и ссылку на исходный код; не пытаться обходить проверку сменой расширения или состава проверенного архива.

## Основания и ограничения

Общее подтверждение автора разрешает публикацию, но не является исчерпывающей проверкой каждого контроллера, NPC, функции и сцены. Проверки сборки/регрессий/пакета фиксируются в финальном RC2-манифесте. Не обещать численный прирост FPS, устранение всех вылетов и регионального эффекта у ЧАЭС. Батарея и инфракрасные режимы — приближения.

После фактической публикации обновить этот файл и RELEASE_STATUS.md: commit/tag/release URLs, SHA архива, ссылки/идентификатор Nexus-файла, Main/Primary и реальный статус скачивания.
